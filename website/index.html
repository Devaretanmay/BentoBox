Why Compart?

Existing platforms give your agent an isolated box. Compart gives you control over your agents and workflows.

Unsandboxed Local Execution

0ms Boot • ZERO Security

Agents execute with full access to host ~/.ssh, ~/.aws, environment variables, and local databases. One prompt injection leaks host secrets.

Docker / Cloud MicroVMs

5s – 30s Boot • Heavy Infrastructure

Isolates execution, but adds heavy container startup lag, requires background daemons, breaks local path mounts, and incurs cloud subscription fees.

COMPART CONTROL LAYER

Compart Sub-Millisecond Kernel Layer

Sub-Millisecond • OS Kernel Isolation

Applies native OS kernel rules (Landlock on Linux, Seatbelt on macOS) directly to process execution. Deny-by-default credential protection with zero Docker overhead.

Quickstart Workflows

Start managing your AI agents in under 60 seconds.

# 1. Initialize an agent workspace
compart init

# 2. Define workflow compartments
compart compartment create Research
compart compartment create Builder

# 3. Wire agent communication edges
compart connect Research Builder

# 4. Inspect declared topology
compart inspect

# 5. Execute under OS kernel isolation
compart run
from compart import AgentCompart, Compartment
from compart.compartments import CompartmentConfig

# Initialize agent outer container with auto-loaded proxy & snapshots
agent = AgentCompart(workdir=".")

# Add inner compartment with explicit permissions
agent.add(Compartment(
    name="Builder",
    fn=lambda ctx: print("Building code safely..."),
    config=CompartmentConfig(permissions=["fs_read", "fs_write", "fs_exec"])
))

# Execute workload
result = agent.run()
print(f"Status: {result.status} | Files changed: {result.diffs}")
import * as compart from '@compart/sdk'

// Native OS kernel sandbox check
if (compart.sandboxSupported()) {
  // Permission verification
  const allowed = compart.runtimeCheckPermission(
    JSON.stringify({ permissions: ['fs_read'] }),
    JSON.stringify(['fs_read']),
  )

  // Command blocklist check
  const safe = compart.runtimeCheckCommand('rm -rf /') // false (blocked)

  // Topology runtime handle
  const rt = new compart.Runtime(configs, JSON.stringify([['fetch', 'build']]))
  console.log(rt.runOrder()) // ['fetch', 'build']
}
